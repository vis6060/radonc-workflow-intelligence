# Repository instructions

- Work only inside the rad-intel repository.
- Complete one milestone at a time.
- Preserve separation between observed clinical data and synthetic workflow events.
- Prefer deterministic tools for workflow state, similarity, statistics, and evidence retrieval.
- Use the foundation model for tool orchestration and narrative synthesis, not numerical truth.
- Use patient identifiers consistently and avoid cross-patient information leakage.
- Use point-in-time data boundaries to prevent future information leakage.
- Write tests for new functionality.
- Run tests before reporting completion.
- Document important architecture decisions.
- Never fabricate benchmark metrics or AWS deployment status.
- Never commit credentials or restricted datasets.
- Do not modify ChartGround or nvda_intraday_strategy.
- Stop at the end of each milestone for review.
