# Roadmap

- **M0 — Repository foundation:** package structure, schema contracts, safety
  boundary, development rules, and local quality checks.
- **M1 — RADCURE ingestion:** inspect and normalize the approved dataset with
  provenance, data-quality reporting, and tests.
- **M2 — Synthetic workflow generation:** generate clearly labeled operational
  histories while preserving separation from observed clinical records.
- **M3 — Deterministic intelligence tools:** reconstruct workflow state, retrieve
  evidence, calculate similarity, and summarize descriptive statistics.
- **M4 — Strands/Bedrock agent:** orchestrate deterministic tools and synthesize
  evidence-linked operational narratives.
- **M5 — AgentCore deployment:** package and deploy the agent to Amazon Bedrock
  AgentCore Runtime with operational controls.
- **M6 — Four-panel application:** demonstrate context, workflow state, similar
  patients, and historical next-step patterns.
- **M7 — Quantitative evaluation:** measure accuracy, evidence support, safety,
  latency, and cost with isolated gold labels.
- **M8 — GitHub documentation:** prepare reviewed public-facing technical and
  usage documentation without restricted data.
- **M9 — Final validation and demonstration:** run end-to-end validation and
  produce the final controlled demonstration.

Each milestone ends with review before work begins on the next milestone.
